# PLC Automatic Bottle Filling System

## Overview

This project demonstrates an **Automatic Bottle Filling System** developed using **Siemens PLC (S7-1200)** and **Ladder Logic Programming**. The system automates the bottle filling process by detecting bottles, controlling the filling valve, and monitoring the operation through an HMI interface.

## Features

* Automatic bottle detection using sensors
* Conveyor motor control
* Automatic filling valve operation
* Filling timer control
* Start and Stop push button operation
* Process status monitoring on HMI
* Industrial automation logic using PLC Ladder Diagram

## System Workflow

1. Press the **Start Button**.
2. The conveyor motor starts moving bottles.
3. When a bottle reaches the filling station, the sensor detects it.
4. The conveyor stops automatically.
5. The filling valve opens for a preset time.
6. After filling is completed, the valve closes.
7. The conveyor restarts and moves the bottle out.
8. The process repeats for the next bottle.
